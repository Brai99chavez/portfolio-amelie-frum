ESTA CARPETA LA GENERA EL COMANDO «npm run fotos» (o «npm run optimize»). NO SE EDITA A MANO.

Una subcarpeta por proyecto o grupo de fotos (brujas, sol, baby, 808, arena, estudio, eventos…, y una por cada proyecto nuevo que
se cargue en «contenido»). Cada foto tiene varias medidas en WebP, con un código en el nombre:

    <id>-<ancho>w-<código>.webp        p. ej.  brujas/brujas-caldero-1080w-1a2b3c4d.webp

manifest.json dice qué medidas tiene cada foto y de qué original salió; el build lo lee.
Para sumar o sacar fotos: mirar «contenido/LEEME.txt».
